#WooCommerce WhatsApp Support Widget

A lightweight, smart, and modular WordPress plugin that adds a floating WhatsApp chat widget to your WooCommerce store.

The plugin automatically detects WooCommerce product pages and includes the product name and URL in the WhatsApp support message, making it easier for customers to ask questions about specific products.

⸻

##🚀 Key Features

* Smart Page Detection: Automatically detects WooCommerce product pages and retrieves the product title and permalink.
* Direct WhatsApp Integration: Opens WhatsApp Web or the WhatsApp mobile app with a pre-filled support message.
* Customizable User Input: Allows customers to enter their questions directly inside the floating chat modal before being redirected to WhatsApp.
* Clean Architecture: Uses native WordPress hooks (wp_footer), secure data passing (wp_localize_script), and separate CSS/JavaScript files without unnecessary third-party dependencies.
* Fully Responsive & Lightweight: Designed for fast performance and a mobile-friendly experience.
