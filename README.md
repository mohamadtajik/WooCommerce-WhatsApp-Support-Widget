# WooCommerce WhatsApp Support Widget

A lightweight, smart, and modular WordPress plugin that adds a floating WhatsApp chat widget to your store. It automatically detects WooCommerce product pages and attaches the product name and URL directly to the WhatsApp support message.

---

## 🚀 Key Features

- **Smart Page Detection:** Automatically identifies if the user is browsing a WooCommerce product page and includes the product title and permalink in the message.
- **Direct WhatsApp Integration:** Opens WhatsApp Web or App with a pre-filled, custom message ready to send.
- **Customizable User Input:** Allows customers to type their specific question directly inside the floating modal before redirecting to chat.
- **Clean Architecture:** Built using native WordPress hooks (`wp_footer`), secure data passing (`wp_localize_script`), and standard CSS/JS separation without heavy third-party dependencies.
- **Fully Responsive & Lightweight:** Designed for high speed and mobile-friendly user experience.
